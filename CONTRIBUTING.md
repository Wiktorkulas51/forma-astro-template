# Contributing

Keep changes focused and follow the existing data and component patterns. Edit the matching JSON file for content changes, then update the component only when its markup or behavior needs to change.

Before submitting a change, run:

```bash
npm run ai:check
npm run build
```

Do not include credentials, private business data, unlicensed assets or generated build output. List the source and license for any new third-party asset in `ASSETS-LICENSES.md`.
