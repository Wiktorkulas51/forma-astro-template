# FORMA

FORMA is a free Astro template for construction and renovation services. It provides English and Polish homepage routes, editable JSON content, a shared component system and a static deployment workflow.

Start with [README.md](../README.md), the [customization guide](guides/customization.md) and [deployment guide](guides/deployment.md).
